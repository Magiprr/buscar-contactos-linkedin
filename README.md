# buscar-contactos-linkedin

Skill para Claude Code que encuentra en LinkedIn a las personas a las que
tienes que escribirles (entrevistas, clientes, alianzas o pedir ayuda),
verifica su cargo actual y te entrega el link al perfil con el mensaje listo
para pegar.

## Instalar

```bash
git clone https://github.com/Magiprr/buscar-contactos-linkedin ~/.claude/skills/buscar-contactos-linkedin
```

Después pídele a Claude, por ejemplo, "búscame a quién escribirle en las
municipalidades de Valparaíso para hablar de emprendimiento".

## Qué necesita

- Un navegador conectado a Claude (el integrado o Claude in Chrome) con tu
  sesión de LinkedIn abierta. Sin navegador, usa búsqueda web.
- Opcional: cuenta gratis de Apollo abierta en el navegador.

Claude solo lee. Las solicitudes y los mensajes los mandas tú.
